# LC H3 Library 📚

Ready-made pictures for the **LC H3 Story** cards. Pick one with **📚 Library** in a card's picture picker: it downloads once and lands on the card, and an empty card gets the text below too.

- Paste the **card text** into the card's look / description if you use the picture another way.
- Cast cards are headshots: give every person an outfit card for their clothes.
